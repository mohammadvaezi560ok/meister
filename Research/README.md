## Nicht automatisch ladbar

Diese Quellen blockieren automatische Browser aus Rechenzentren. Am besten lokal im eigenen Browser sichern:

- **AliExpress**: leitet auf eine Captcha-Seite um (`aliexpress.us/.../punish`).
- **Amazon**: Bot-Zwischenseite auf allen `/dp/`-Seiten.
- **Walmart**: Bot-Prüfung, die Seite lädt keine Produktbilder.
- **YouTube**: verlangt aus Rechenzentren einen Login. Lokal klappt `yt-dlp` normal, notfalls mit `--cookies-from-browser chrome`.
- **Instagram**: Reels sind ohne Login nicht durchsuchbar und nicht ladbar.

## Automatisch befüllen

```bash
pip install playwright "yt-dlp[default,curl-cffi]" pillow
playwright install chromium

python3 Research/tools/download.py    # Shopseiten + Advertorials: Screenshots, Produkt-/Bewertungsbilder, Shop-Videos
python3 Research/tools/meta_ads.py    # Meta-Werbebibliothek: Ads als Video/Bild + ads.csv
```

- `tools/download.py` geht die `seiten` aus `tools/quellen.json` durch. Es scrollt jede Seite, damit Lazy-Load-Bilder und Bewertungen nachladen, macht einen Full-Page-Screenshot, lädt alle Bilder in Originalgröße und legt sie im passenden Ordner ab. Duplikate und Icons werden aussortiert. Die `videos` (YouTube) lädt es mit yt-dlp in bester Qualität.
- `tools/meta_ads.py` fragt die Werbebibliothek ohne Login ab. Ohne Login liefert sie pro Abfrage nur 30 Ads, deshalb zerlegt das Skript jede Abfrage in Varianten (Bild/Video × aktiv/inaktiv × Sortierung). Es behält nur Ads, die auf einen bekannten Konkurrenten verlinken und im Text vom Kniekissen handeln. Nourials andere Produkte (128-Hz-Stimmgabel, Tinnitus, Nackenkissen) fliegen raus.
- TikTok-Videos lädt man mit `yt-dlp` (benötigt `curl-cffi`). Für die Suche eignen sich die Hashtag-Seiten `#kneepillow`, `#kneepillowforsidesleepers`, `#sidesleeperpillow`, `#legpillow` und `#kniekissen`.

Neue Shops kommen in `tools/quellen.json` (`seiten`, `meta_ads` oder `videos`). Danach das Skript erneut starten. Bereits geladene Dateien werden per Inhalts-Hash erkannt und nicht doppelt gespeichert.
